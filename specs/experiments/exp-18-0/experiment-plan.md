# Exp 18.0 Experiment Plan

- Spec version: 0.1.0
- Status: draft

## Objective

Validate the deterministic baseline of the governed agent runtime before
connecting an LLM or orchestration framework.

## Main result

A reproducible runtime capable of evaluating valid, invalid, premature and
policy-violating proposals across scenarios S01-S12.

## Boundaries

Exp 18.0 does not include an LLM, LangGraph, Langfuse or real infrastructure
actions.
