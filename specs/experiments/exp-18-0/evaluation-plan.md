# Exp 18.0 Evaluation Plan

- Spec version: 0.1.0
- Status: draft

## Runtime measures

- policy violation containment;
- critical precondition bypasses;
- false blocks;
- safer-path success;
- confirmation binding;
- trace completeness.

## Product measures

- time to useful outcome;
- total and unnecessary tool calls;
- acceptable next-step rate;
- contained premature actions;
- clarification and escalation outcomes;
- latency and estimated execution cost.

Exp 18.0 establishes the deterministic measurement baseline for later
comparison with fixed workflows and bounded LLM agents.
